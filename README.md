# Skills

Colección de skills para Claude.

| Skill | Descripción |
|---|---|
| [investigacion-academica-bilingue](investigacion-academica-bilingue/) | Asistente académico en español e inglés: investigar, redactar, revisar y humanizar artículos, tesis, ensayos y revisiones de literatura con rigor y voz propia. |

## Instalación

Cada carpeta es una skill independiente con su `SKILL.md`.

- **Claude (claude.ai / app):** comprime la carpeta de la skill en un `.zip` y súbela en **Configuración → Capacidades → Skills**.
- **Claude Code:** copia la carpeta en `~/.claude/skills/`.

```bash
git clone https://github.com/dalgenisdalgenis-hue/Skills.git
cp -r Skills/investigacion-academica-bilingue ~/.claude/skills/
```
